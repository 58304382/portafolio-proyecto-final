INGENIERIA DE SOFTWARE

Breve descripción del proyecto:
Proyecto enfocado en el desarrollo de soluciones web modernas mediante el uso de tecnologías web y consumo de APIs. Durante el desarrollo se implementaron aplicaciones funcionales como un sistema de consulta de tipo de cambio en tiempo real y una plataforma de gestión de tickets de soporte, orientadas a la automatización y administración de procesos. Además, se diseñaron interfaces dinámicas, intuitivas y responsivas para mejorar la experiencia del usuario y optimizar el manejo de la información.

Sección 3: Funcionalidad

Evidencia visual del funcionamiento del sistema y consumo de API.

HU1 - Tipo de Cambio

API utilizada
Exchange Rate API

Descripción de la API
Se implementó la API ExchangeRate-API para consultar tasas de cambio actualizadas y realizar conversiones dinámicas de moneda en tiempo real. Durante el desarrollo, se realizaron pruebas y validaciones de consumo API mediante el cliente de pruebas Postman, verificando el correcto funcionamiento de las peticiones y respuestas obtenidas.

Pasar cursor para ver evidencia

HU2 - Consultar tickets de soporte

API utilizada
API REST

Descripción de la API
API REST desarrollada utilizando ASP.NET Core para gestionar y consultar tickets de soporte, permitiendo visualizar incidencias, prioridades, estados y seguimiento de solicitudes mediante comunicación entre frontend y backend. La información se muestra dinámicamente dentro de la interfaz del sistema.
